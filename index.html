01

Two kinds of knowledge

Document retrieval handles policies, supplier records, product information, and quality reports. A separate read-only SQL tool answers questions over synthetic sales data.

02

Evidence is visible

Answers include citations or a record of the tool used, so a person can inspect how the assistant reached its response.

03

Quality is measured

Retrieval strategies can be compared against labeled questions. Application tests run in CI before deployment; MLflow records evaluation runs.
